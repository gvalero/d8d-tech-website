## No external image, tracker or font request

The site intentionally uses **no downloaded photographs, stock imagery, image CDNs, web-font CDN, analytics script, advertising pixel, customer-data service or social embed**. The `client/index.html` file contains no third-party script tag. A browser review should therefore show only local development/build requests.

## Future-use rules

1. Record source URL, licence version, attribution wording, creator, acquisition date and changes before adding any new external asset.
2. Do not use a third-party device, marketplace, manufacturer or certification logo without explicit rights and a factual reason to use it.
3. Do not purchase stock assets, domains or subscriptions without separate owner approval.
4. Recheck name/logo clearance before public launch or a print order; this provenance record is not clearance evidence.
